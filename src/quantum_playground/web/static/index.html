Quantum Playground Studio

Simulate, compose and run quantum experiments locally, on calibrated device models, or on real IBM Quantum hardware — plus a complete historical Enigma lab with a reversible Grover key-search oracle.

Backends

Quick start

  1. Circuit Lab — drag-free composer with live amplitudes and Bloch spheres.
  2. Experiments — 21 self-verifying experiments (CHSH, teleportation, Shor, VQE, BB84 …).
  3. Pick ibm:fake_fez to rehearse the exact IBM pipeline offline with real calibration noise.
  4. Add your IBM Cloud API key under IBM & Cloud, preflight, then submit with confirmation.
  5. Cloud jobs land in Jobs and are analysed automatically when they finish — even in a later session.

Credentials stay in memory unless you explicitly save them to Qiskit's account store (~/.qiskit). Nothing is written to the project folder.

Safety rails

        
    
          
  • Real-QPU submissions always need an explicit confirmation.
    • 
          
  • Every submission is transpiled first; circuits above the native two-qubit cap are blocked unless you override.
    • 
          
  • ibm:fake_* runs the identical pipeline locally with the device's calibrated noise — rehearse there first.
    • 
          
  • The calibration "error product" is an illustration (independent errors), not a fidelity prediction.
    • 
        

        
AWS Braket

        
braket:local runs Braket's simulator offline. Managed devices use your normal AWS credential chain (AWS_PROFILE) and the spec braket:<device ARN> from the CLI.
